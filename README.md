# Handboll – Samåkning

Mobilanpassad React/Vite-prototyp för samåkning.

## Lokal utveckling

`npm install`
`npm run dev`

## Nuvarande funktioner

- Veckoöversikt
- Hela körschemat
- Historikmarkering
- Manuell överskrivning av körning
- Körsaldo
- Närvaro/körbarhet
- Automatisk fördelning efter körningar per deltagande

## Nästa steg

Koppla appen till gemensam databas/backend (t.ex. Supabase) så att alla användare delar samma data. Sedan kan repot kopplas till Vercel för automatisk publicering.
